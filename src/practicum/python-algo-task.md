# Решение задач на Python и анализ сложности

> Опирается на главы [«Введение в алгоритмы»](../cs/basic-algos.md) и [«Сложность операций с коллекциями»](../dev/python/o-notation.md).


**Задача:** реши **две** любые задачи «легкого» уровня с сайта [CodeRun от Яндекса](https://coderun.yandex.ru/).

## Что сдавать

По каждой из двух задач:

1.  **Ссылка на задачу.**
2.  **Исходный код** решения на Python.
3.  **Пояснение:** подробно опиши ход своего решения.
4.  **Обоснование:** объясни, почему выбран этот алгоритм и эти структуры данных (например, список, словарь, множество).
5.  **Анализ сложности:**
    *   **Временная сложность** (Big O Notation).
    *   **Пространственная сложность.**

**Цель:** Научиться не только писать рабочий код, но и понимать его эффективность.
